Jamly

Jamly is a web platform designed to help musicians find other musicians, create profiles, connect with people nearby, and form bands or music projects

Features:
1. User registration and login
2. Musician profiles
3. Instrument selection
4. Genre selection
5. Experience level
6. Search for musicians by location
7. Messaging between users
8. Notifications
9. Profile editing
10. Profile pictures
11. Terms of Service and Privacy Policy

The project is built with:
1. HTML
2. CSS
3. JavaScript
4. Node.js
5. Express.js
6. MongoDB


Goals:
The goal of Jamly is to make it easier for musicians to find people to play with.

Project Status: In active development
